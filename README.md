
# Travel Ease - Travel Discovery & Booking Platform

## Overview
Travel Ease is a simple frontend travel website that helps users discover destinations, compare budgets, and plan trips in one place.

## Problem Statement
Travellers face several challenges when planning a trip:
1. Travel information is scattered across different platforms
2. Difficult to find trustworthy reviews and clear pricing
3. No easy way to filter destinations by budget and interest
4. Users lose track of places they want to visit

## Solution Provided
Travel Ease solves these problems by providing:
- A centralized platform for destination discovery
- Verified reviews and transparent pricing
- Smart search and filter by category (Beach, Mountain, Culture) and budget
- Simple and fast booking process

## Features Implemented
- Dynamic destination cards using JavaScript Array of Objects
- Search functionality by destination name
- Filter by category and budget
- Responsive booking form with validation
- Clean and responsive UI with CSS Grid & Flexbox
- Interactive DOM manipulation

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
